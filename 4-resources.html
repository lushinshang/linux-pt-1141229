🌐 推薦學習網站

HackTheBox

🔗 https://www.hackthebox.com/

線上滲透測試練習平台，提供各難度等級的靶機。適合從入門到高級的使用者。

VulnHub

🔗 https://www.vulnhub.com/

開源靶機分享平台，免費提供各類靶機和練習環境。社群驅動，靶機多樣。

TryHackMe

🔗 https://tryhackme.com/

互動式資安教學平台，提供結構化的課程和實驗環境。適合初學者。

PortSwigger Web Security

🔗 https://portswigger.net/web-security

專業的 Web 應用安全訓練課程，包含實驗室環境。Burp Suite 開發者提供。

CEH (Certified Ethical Hacker)

難度：⭐⭐⭐　投資回報：⭐⭐⭐⭐

入門級認證，最受認可的資安認證之一。適合開始安全職業生涯。

OSCP (Offensive Security Certified Professional)

難度：⭐⭐⭐⭐⭐　投資回報：⭐⭐⭐⭐⭐

進階級認證，業界最硬的滲透測試認證。需要 24 小時實戰考試。

eJPT (eLearnSecurity Junior Penetration Tester)

難度：⭐⭐　投資回報：⭐⭐⭐

初級認證，適合完全初學者。較容易取得，是進階認證的基石。

GWAPT (GIAC Web Application Penetration Tester)

難度：⭐⭐⭐⭐　投資回報：⭐⭐⭐⭐

Web 應用專項認證，由 GIAC 頒發。適合專注於 Web 安全的人員。

🛠️ 必備工具清單

Nmap

網路埠和服務掃描的標準工具。用於網路偵察階段。

Dirb / FFuf

目錄和路徑掃描工具。發現隱藏的 Web 目錄和頁面。

Nessus

專業的漏洞掃描工具。自動檢測系統漏洞，免費版支持 16 個 IP。

LinPEAS

Linux 提權漏洞自動掃描工具。幫助發現系統提權點。

WinPEAS

Windows 版本的提權掃描工具。Windows 系統提權查找。

Metasploit Framework

一體式滲透框架，包含掃描、利用、後滲透等功能。業界標準工具。

Burp Suite

Web 應用測試平台。用於攔截、修改和測試 HTTP 請求。

SQLMap

SQL Injection 自動化工具。簡化 SQL 注入漏洞利用。

John the Ripper

密碼破解工具。用於破解各種密碼雜湊。

Hashcat

高性能密碼破解工具。支持 GPU 加速。

Netcat (nc)

網路工具，用於監聽埠和建立反向連接。非常強大的多功能工具。

SSH

安全的遠程登入協議。用於安全的遠程訪問。

Curl / Wget

檔案下載工具。在目標系統下載攻擊工具。

Reverse Shell Generator

快速生成反向 Shell 代碼的工具。支持多種語言和框架。
