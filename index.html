📚 8 個實戰階段

完整的滲透測試流程：

1️⃣
網路偵察
使用 Nmap 掃描靶機的開放埠和服務
2️⃣
Web 列舉
用 Dirb 掃描發現隱藏的目錄和頁面
3️⃣
登入繞過
利用 SQL Injection 繞過身份驗證
4️⃣
WebShell 部署
上傳 PHP 並執行系統命令
5️⃣
反向 Shell
建立從靶機回連的 Shell
6️⃣
提權掃描
用 LinPEAS 自動偵測漏洞
7️⃣
提權利用
PATH 劫持、SUID 等多種方法
8️⃣
目標達成
取得 Flag，完成滲透測試
