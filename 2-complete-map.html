🔄 攻擊流程全景圖

攻擊流程：偵察 → 掃描 → 列舉 → 漏洞檢測 → 利用 → 提權 → 目標達成

📈 8 大階段時間軸

1️⃣ 網路偵察

目標： 使用 Nmap 掃描靶機的開放埠和服務

成功標誌： 發現 HTTP 服務在 80 埠

2️⃣ Web 應用掃描

目標： 用 Dirb 掃描發現隱藏的目錄和頁面

成功標誌： 找到 /index.php、/upload.php、/dashboard.php

3️⃣ 漏洞分析

目標： 分析應用程式漏洞，測試 SQL Injection

成功標誌： 發現登入頁面存在 SQL Injection

4️⃣ 登入繞過

目標： 利用 SQL Injection 繞過身份驗證

成功標誌： 成功登入獲得 Session Cookie

5️⃣ 檔案上傳

目標： 上傳 WebShell 到伺服器

成功標誌： 上傳 PHP 檔案並在 /uploads 目錄找到

6️⃣ 反向連接

目標： 建立從靶機回連攻擊機的交互式 Shell

成功標誌： 獲得 www-data 使用者的 Shell

7️⃣ 提權掃描

目標： 用 LinPEAS 自動掃描系統提權漏洞

成功標誌： 發現 sudo /usr/local/bin/runbackup 可執行

8️⃣ 權限提升

目標： 利用發現的漏洞提升到 root 權限

成功標誌： 獲得 root shell，取得 Flag

🎯 關鍵決策點表

階段 關鍵決策 成功標誌
偵察 發現開放埠 找到 HTTP 服務
掃描 發現登入頁面 找到 /index.php
漏洞 確認 SQL Injection 成功繞過登入
上傳 繞過檔案驗證 上傳 PHP 檔案
反向 建立反向連接 獲得交互式 Shell
掃描 找到提權點 發現 sudo 程式
提權 利用漏洞 取得 root 權限

💡 攻擊流程特性

🔄 循序漸進

每個階段都建立在前一個階段的基礎上。上一階段的失敗會導致整個攻擊鏈失敗。

🔀 可選路徑

在某些情況下，可能存在多條路徑達到相同目標。例如有時可能直接找到配置檔案而跳過某些步驟。

⏱️ 時間成本

整個流程從開始到結束可能需要 30 分鐘到數小時，取決於目標系統的複雜度和防禦措施。

🎯 成功關鍵

每個階段都有明確的成功標誌。如果無法達到該標誌，需要嘗試替代方法或重新評估。
