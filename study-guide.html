📋 學習進度檢查清單

基礎知識檢查

  • 理解滲透測試的概念和倫理框架
  • 熟悉 Nmap 的基本使用
  • 能用 ffuf 進行目錄掃描
  • 理解 HTTP 狀態碼的含義
  • 理解 SQL 注入的原理

實戰技能檢查

  • 能進行 SQL Injection 登入繞過
  • 能上傳和執行 WebShell
  • 能建立反向 Shell 連接
  • 能進行 PATH 劫持提權
  • 能使用 SUID 提權
  • 能執行反向 Shell 提權

防禦知識檢查

  • 知道如何防止 SQL Injection
  • 知道如何安全處理檔案上傳
  • 知道如何正確配置 sudo 權限
  • 知道為什麼應該使用絕對路徑
  • 能提供改進安全的建議
💡 學習小秘訣
  • 1. 不要跳過理論： 先理解原理再動手，能大大加快學習速度。
  • 2. 做小測驗： 每章都有測驗，做完能確認您是否真的理解了。
  • 3. 寫代碼時動手： 不要只看，要跟著敲一遍，這樣才記得住。
  • 4. 反複練習： 在不同的靶機上反複進行整個流程。
  • 5. 記住防禦： 理解漏洞最好的方式是學會防禦它。
